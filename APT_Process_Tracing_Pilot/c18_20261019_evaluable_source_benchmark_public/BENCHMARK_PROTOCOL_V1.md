# BENCHMARK_PROTOCOL_V1 — attack-control ingress tracing

Status: frozen eligibility protocol; no admitted pilot, no performance result. All currently inspected material is DEVELOPMENT_EXPOSED.

## Query and independent answer

A query B is one independently attack-related historical event with an original source digest, unique Event or record key, host, native time, actor/object roles and a separately stored mapping basis. A method may receive the original observation and approved earlier context; it receives neither the attack explanation, answer A, attack script, evaluator labels nor future records. Source hashes and physical record order do not establish execution order.

The main answer level is an inbound connection/session INSTANCE of attack-control entry for this B. An address or five-tuple alone is insufficient: preserve the instance/lifetime boundary, receiving process identity, host, inbound direction and native time. Outbound loader operations, process-entry candidates, file entries and broad adversary attribution form separate ALTERNATE_SOURCE_LEVEL groups; their ranks must not be pooled with session-instance ranks.

Reference selection precedes raw query checks. A publisher-supplied event binding and an independently audited researcher mapping are distinguished. A posthoc researcher mapping must record every host/execution/action/object/time anchor and ambiguity; it cannot be renamed publisher gold. Current qualification used one exposed analyst, without a two-reviewer agreement claim. Labels, observations, query code and evaluator are separate chains. No algorithm result, reachability or chosen time-offset can select the reference.

## Candidate universe and permitted evidence

Before a run, declare a universe from observed ingress instances in the approved execution scope, using documented instance rules and normal observations; do not use the algorithm-returned nodes or A alone as the universe. Keep unknown/unobserved instances separate. Two sessions from the same address remain distinct when original stable instance identities distinguish them. Repeated rows for one identity do not make a nontrivial universe. A one-element universe is TRIVIAL_CANDIDATE_UNIVERSE and cannot substantiate ranking performance. Unknown universe size is NOT_ESTABLISHED, not zero.

A raw-support segment retains source hash/key, original direction, event type, host, native time and identity qualification. Observed parent creation and input operations remain distinct from a parent reference whose creation is missing. MAY_STATE_CARRY, producer candidates, missing object versions and temporal ties are explicit limitations. Same process, common endpoint or an ordered story is not observed byte flow. No cross-host join is formed solely from a matching address, tuple or identifier string.

B2+A2 for the same execution is necessary for source evaluation. A GO additionally needs available observations and a nontrivial predefined candidate universe; a valid answer outside the observed universe is a coverage/conflict finding, not silently removed. P1 can support limited evidence validity and coverage checks; it does not become an attack-edge reference. This round did not construct a candidate universe because no main-level A2 exists.

## Metrics, multiple answers and abstention

Only admitted B2+A2 cases with a fixed universe may later use Source Hit@K and MRR. Preserve the independently acceptable A set; do not choose its member from Top1. A hit means at least one independently acceptable instance is returned within the allowed K. For score ties, use a predeclared pessimistic rank (all tied candidates ahead of an acceptable answer) for both Hit@K and reciprocal rank. An unreturned acceptable answer contributes reciprocal rank0 only when the case, universe and output budget are qualified; coverage-incomplete and non-identifiable cases remain separately reported.

Path/Edge precision, recall or F1 require P2 independently referenced edges/segments and explicit scope. P1 alone only permits reporting legal evidence, gaps and coverage. Source metrics are NOT_EVALUABLE when B2+A2 is absent; Path-F1 is NOT_EVALUABLE without P2. No missing metric is filled with0. UNRESOLVED is a permitted abstention for missing observations or identity, not an automatic false positive/negative. Only an independently proved benign execution is BENIGN_GOLD; absence of an attack label permits at most UNLABELED_CONTROL.

## Input isolation, grouping, resources and baselines

A qualified future case must freeze a method-visible B file, reference-only answer/attack-membership file and eligibility/coverage receipt before execution. The loader must reject reference-only files. Future logs, source answers and full attack plans stay evaluator-only. Until that separation is executable and verified, describe it as a protocol, not as demonstrated OS isolation.

Split by independent execution, capture scenario and script family. Neighboring events from one execution cannot cross development/test. Distinct APT29 captures remain one scenario family for a family-held-out evaluation. A later n=1 qualifying instance is PILOT_ONLY, with no generalization, significance or model-superiority inference. A larger benchmark needs at least3 independent executions and2 distinct ingress instances, plus background and a documented split.

B0 denotes the project's explicitly self-built bounded raw-dependency diagnostic. DEPIMPACT remains AUTHOR_EXAMPLE_SMOKE_ONLY_AND_EVENT_POI_MISMATCH: the already executed author example does not count as an E5 event-POI baseline. No author binary, model, full-graph search or ranking experiment was run in C18. Without B2+A2, baseline smoke is BASELINE_SMOKE_NOT_RUN. Synthetic guard tests are not a real case or algorithm metric.

Any future admitted interface smoke is a separate authorized operation, at most60 seconds with fixed entity/edge limits and no answer-file access. This protocol does not authorize it now. Native integer nanoseconds and actual timestamp precision must be retained; no fitted report-clock shift is injected. Current qualification uses at most100 indexed points,30 seconds per statement,3 direct hops and200 returned candidate records per execution. No unbounded search, new raw download, compressed-member replay, new installation or system changes are permitted by this protocol.
