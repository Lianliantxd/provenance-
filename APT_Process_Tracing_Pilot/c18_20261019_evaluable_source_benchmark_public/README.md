# C18 evaluable attack-control ingress benchmark admission

Result: C18_B_EVENT_ONLY_NO_SOURCE_INSTANCE, with NO_GO_FOR_SOURCE_RANKING_METRICS. Six dataset families were checked at bounded asset or execution level. Four fixed execution candidates were reviewed; one has an independently mapped attack-related B event, but none has a qualified inbound connection/session-instance A for that B. No source pilot was admitted.

The strongest partial case is an existing OTRF APT29 capture with same-version author-plan correspondence and preserved raw locators. Its B mapping is researcher posthoc qualification, not publisher event gold or a blinded reference. Observed process lineage does not identify an attack-control ingress session. No source retrieval or path F1 score was generated.

Work performed: seven indexed event points, two schema statements and two fixed original text records, with no compressed-log replay. The dataset directory search used depth2 and a500-file cap per root; a truncated root is explicitly reported. Documentation of STARC annotations was distinguished from a locally present annotation file. Derived configuration/step labels and unofficial event labels were not substituted for ingress references. No baseline, author binary, model, GPU, attack execution, new dataset acquisition or installation was run.

Only abstract eligibility, a future protocol and pure guard functions are public. The guards are not a tracing algorithm, not a reference generator and not a real-case pilot. Private execution mappings, raw identifiers, native event snippets, reference answers, source paths and credentials are excluded.

The only proposed missing artifact is an independently sourced entry-instance binding for the already fixed terminal event in the strongest partial case. Its published filename, size and access permission are not established; it was not acquired. No next stage was launched.
