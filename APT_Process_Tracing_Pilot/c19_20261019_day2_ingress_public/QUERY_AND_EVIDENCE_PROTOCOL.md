# Query and evidence protocol

The process endpoint and ingress definition were frozen before candidate queries. Native system-monitor times use a thirty-minute window ending at the fixed endpoint. Other providers use a separately declared collection-time retrieval envelope; their operation times remain unverified and are not admitted as pre-endpoint method observations.

Queries use the existing database in read-only mode, fixed hosts/providers/event types, parameterized predicates, per-statement thirty-second deadlines, a two-hundred-statement ceiling, and ten-thousand billed rows including duplicates and has-more probes. An exact five-tuple peer check corroborates endpoints only. It never equates a transport with a remote shell or chooses the nearest event as a reference.

A2 requires scoped instance identity, receiving lifecycle, inbound control direction, independent execution binding, raw locators, and resolved competitors. An observed parent, port, or successful logon alone fails this gate. Missing index columns are distinguished from missing original telemetry. Query-result completion does not imply complete capture or a qualified candidate universe. Source ranking and path metrics remain disabled.
