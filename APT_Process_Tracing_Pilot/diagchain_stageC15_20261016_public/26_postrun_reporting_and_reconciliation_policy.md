# C15 post-run reporting and same-attempt reconciliation policy

All 18 assigned model runs already have original terminal records. There will be no new model calls, new attempts or sample replacements. Before any Gold read, source code for metadata/cost disclosures and a narrowly bound completion reconciliation is frozen here.

The last C1 R3 OFF has a local bridge failure after four acknowledged responses, but read-only same-attempt status reports PREDICTION_FROZEN. Only if all native frozen hashes, original request/response envelopes, prompt/reply bytes, consumed ACKs and identities match may existing artifacts be transferred and acknowledged. The original FAILED terminal and state-machine history remain untouched. A separate terminal_resolution records the native completion and zero new generations. This is a same-attempt completion reconciliation, not a replacement trial. Batch sealing and reporting use the bound resolved record and preserve the original failure count explicitly.

Reporting keeps official evaluation results unchanged. It adds per-unit parser/SSH versions, native terminal reasons, actual phase launches, available failed-turn token usage with coverage, and calendar versus active runner time. Missing failed-turn usage is not filled with zero, observed sums are not exact bills, and low-cost early failure is not equivalent completed work. Each case retains three assigned repeats per arm, NA failures, median/sample-SD/range and paired differences. No cross-case F1 mean, extra significance test, selective post-score regeneration or semantic-truth claim is introduced. The optional reflection snapshot diagnosis is not performed.
