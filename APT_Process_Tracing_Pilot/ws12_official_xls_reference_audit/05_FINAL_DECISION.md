# 终止决定：OFFICIAL_MATERIAL_STEP_ONLY

本轮选择状态 **B：`OFFICIAL_MATERIAL_STEP_ONLY`**，并**结束以现有 WS12 官方 XLS/A1–A6 获取跨操作事件对真值的分支**。官方工作簿和注释确有攻击命令、阶段、时间及路径；本机 ETW 另外直接记录了两条 `ParentID` 父子关系。但材料未给出具体原始写入事件与读取/执行事件之间的内容流、文件版本或唯一事件 ID 对。官方 A2 的 agent 标识还与本次后续启动记录不一致，不能通过挑选看起来最像的事件来补齐真值。

合格的官方跨操作事件对数为 **0**；传感器直接父子对为 **2**；同路径模型候选为 **2**；一条“读取导致先前启动”的解释被时间反证。A1–A6 是六份步骤注释，不是六条依赖 GT。`outputs/opid_occurrences.json` 的 1 次官方标识命中为较早的 `Process/Stop`，不是目标启动。原始偏移和哈希可确认这些操作存在，但不证明攻击因果。

按事先冻结的条件，本轮不新跑基线。既有预算 8 的限定实验对两条父子关系为 2/2；这类直接关系已被简单规则处理，不能据此提出新的依赖恢复算法优势。当前**没有**可进入第四研究内容算法创新阶段的独立证据。暂定的“证据可识别性约束与保守攻击溯源”仍可作为问题表述，但不能仅靠 WS12 官方表制造边级评价或声称超越既有方法。此结论只否定**这套材料在本轮用途**，不表示数据不存在、攻击过程不真实，或整个研究方向失败。
