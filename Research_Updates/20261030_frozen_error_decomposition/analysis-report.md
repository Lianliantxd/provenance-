# 冻结结果误差分解：候选前沿与事件预算集中

本轮没有重新训练、生成新预测或调整阈值。核验了既有148份输出、120个同输入/同预算切片的完整模块对照，并对已有压缩测试表进行一次526169行的只读查询。所有结论限于同一个已曝光开发案例的节点调查检索。

## 1. 主要问题与比较单位

固定问题是：漏失发生在评分输入、候选生成还是输出排序/预算阶段？完整模块相对预定简单方法的改善是否需要两个模块共同存在？

输入A为作者压缩事件，B为同范围、同操作白名单的压缩前事件。使用同一冻结Q和原有预算。148份输出不代表148次独立攻击，12个预算切片也不代表12个独立样本。这里只做可复核的描述性比较，不给p值、泛化置信区间或显著性结论。

## 2. 主预算漏失分解

已经通过实际节点集合验证嵌套关系，而非仅用汇总数量相减。A/B两者的评分域和候选参考数量均满足以下关系。

|环节|参考节点数|该环节排除的参考节点|
|---|---:|---:|
|固定参考全集|43|—|
|进入测试评分域|41|2|
|进入候选集合|24|17|
|完整模块主预算输出|22|2|
|A上预定异常排序主预算输出|23|1|

完整模块21个漏失中，19个发生在排序之前，占90.48%。这不是19个已确认攻击活动缺失，也不证明参考全集已完整；它是当前43节点参考下的阶段分解。

针对17个“已评分但候选外”的节点，已扫描已有压缩测试表：**17个全部在Q告警窗口内**。因此不能归因为告警窗口未覆盖；当前定位为候选前沿规则排除。还没有区分具体是三跳上限、前后8个时间组、300秒门限、并列时间弃权，还是输入缺少连接关系造成。50k候选截断未触发，不能将其写成主要阻断。

## 3. B上的排序下降与预算集中

|输入与排序|实际节点|实际事件|不同有向实体对|最大实体对占用事件|参考命中|
|---|---:|---:|---:|---:|---:|
|A异常排序|100|290|266|3（1.03%）|23|
|B异常排序|20|500|6|493（98.60%）|13|
|B时间排序|38|500|74|403（80.60%）|21|
|B完整模块|100|331|286|14（4.23%）|22|

B异常排序的500条记录具有500个不同原生事件事实，不能称为伪造重复、已证实冗余或正常噪声。能够确认的是：事件预算集中在相同实体对，覆盖很少的新节点。

在已经完成的敏感性对照中，固定B输入、Q、候选集和异常排序，仅将事件上限500放宽为2000后，实际输出100节点/858事件，命中由13增加至23。它支持“500事件预算截断对该下降有实质影响”，不证明无成本的新算法增益，也不据此改选主预算。

## 4. 对复杂模块的判断需要限定

上轮主预算下无增益的结论仍成立，但不能扩大为所有预算都无改善。实际观察到：

|预算（节点/事件）|A普通传播→完整模块|B普通传播→完整模块|
|---|---:|---:|
|25/500|18→19|19→19|
|50/500|20→22|20→22|
|100/500|22→22|22→22|
|200/500|23→23|23→23|
|100/100|20→20|20→20|
|100/2000|22→22|22→22|

小预算1—2节点的改善是真实描述结果，应保留。但是在全部12个输入×预算切片中，完整模块的节点命中均与仅操作门控、仅传播记忆相同；每个切片的5个保持行转移量的随机路由种子也均达到或超过完整模块的命中数。因此未识别出两个模块共同存在、或特定邻居分配不可替代的价值。此处“相同”仅指该节点命中指标，不表示事件输出完全相同，也不表示理论等价。

主预算A异常排序命中的23个参考节点包含完整模块的22个，无完整模块独有参考命中。与时间排序、普通传播相比，完整模块在该主预算命中的参考节点集合相同。所有具体节点/事件交集数量已以脱敏计数保存在FULL_MODULE_CONTRASTS.csv。

## 5. 唯一优先行动

`LOCALIZE_EXISTING_FRONTIER_EXCLUSION_BEFORE_NEW_RANKER`

范围限定为已经存在的冻结事件和候选生成代码，先定位17个漏失分别在哪个前沿条件被截断。允许按参考做事后错误诊断，但任何由此形成的新规则都属于开发结果；不得再把这批节点当作未曝光独立验证。

成功条件：为漏失提供可回查的具体门限或不可达证据，能够区分规则过严与原生关系缺失。失败条件：当前输入不能区分时保留UNKNOWN，不为连通而添加联系，不自动扩展数据源或启动新训练。

目前不把更多投入分配给新的传播排序器。也不因为重复实体对集中就直接删除事件：真实重复访问可能是攻击过程所需证据，任何去冗余策略都需要保留事件回查及独立参考约束。

## 6. Claim candidates

- **Claim：** 当前完整模块21个参考漏失中19个先于排序发生。
  - Source evidence：COVERAGE_PARTITIONS.json、PER_PREDICTION_AUDIT.csv。
  - Allowed wording：当前43节点参考、已曝光案例、固定候选协议下的阶段分解。
  - Forbidden stronger wording：90.48%的APT攻击步骤均被候选规则漏掉。
  - Uncertainty：参考非完整活动/因果标注；尚未定位前沿内部具体条件。
  - Next check：仅定位当前前沿排除条件。
  - Decision：keep。
- **Claim：** B异常排序的主预算存在实体对集中和事件上限影响。
  - Source evidence：EVENT_CONCENTRATION.csv、固定500/2000事件上限对照。
  - Allowed wording：98.60%的返回事件连接同一有向实体对；增加实际事件输出后参考节点命中增加。
  - Forbidden stronger wording：493条都是无用正常噪声，删去即提升攻击过程准确率。
  - Uncertainty：没有完整相关/无关事件标签；不能把访问重复自动等同冗余。
  - Next check：在完整记录可回查前提下讨论预算分配，而非先删除证据。
  - Decision：keep。
- **Claim：** 本轮没有识别联合门控/记忆机制的独立收益。
  - Source evidence：BUDGET_SUMMARY.csv、FULL_MODULE_CONTRASTS.csv。
  - Allowed wording：小预算部分优于普通传播，但单模块和随机路由可匹配；主预算无优势。
  - Forbidden stronger wording：所有数据上复杂机制无效，或与普通传播理论等价。
  - Uncertainty：只有1个已曝光攻击；指标仅为有限节点参考命中。
  - Next check：先定位候选覆盖瓶颈，不自动启动新模型。
  - Decision：weaken。
